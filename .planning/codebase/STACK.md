# Codebase Stack & Technologies

**Date:** 2026-07-30

## Core Stack
- **Language**: TypeScript (v5.8.3)
- **Runtime**: Node.js via Vite (v5.4.19)
- **Framework**: React 18 (v18.3.1)
- **Routing**: React Router DOM (v6.30.1)
- **Styling**: Tailwind CSS (v3.4.17) with PostCSS

## UI Components & Design System
- **Component Library**: Radix UI Primitives, Shadcn UI
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Themes**: next-themes (support for light/dark mode)

## State & Data Fetching
- **Data Fetching/Caching**: Tanstack React Query (v5.83.0)
- **Forms**: React Hook Form with Zod for schema validation

## Tooling & Build
- **Bundler**: Vite with `@vitejs/plugin-react-swc`
- **Linting**: ESLint (v9) with React hooks and refresh plugins
- **Package Manager**: bun/npm (lockfiles present for both)
